# Documentation index

| Folder | What is in it |
|---|---|
| `requirements/` | The client's requirements: the Word document's register and checksum, and the approved amendments as text (the `.docx` itself stays outside git). |
| `decisions/` | Architecture decision records. |
| `standards/` | How screens are designed (`screen-design-standard.md`). |
| `deployment/` | Production on Coolify, the deployment plan, hardening, release plans, setup issues. |
| `audits/` | Dated audits and their fixes (owner dashboard 1 Nov 2026, production readiness 21 Oct, audit fixes 20 Oct, the test-data cleanup proposal). |
| `finance/` | Opening cash and stock, the doctor statement reconciliation, the financial go-live data sheet, the Arabic handover for the owner and the accountant. |
| `halls/` | IMED hall bookings: finalisation notes and screenshots. |
| `integrations/` | `xstudio/` (analysis, tasks, sync, screenshots), `library/` (SQL Server analysis), the import data standard and `import-samples/`. |
| `assistant/` | The AI assistant: architecture, tools, setup. |
| `known-issues.md` | The living list of open issues and what waits on whom. |

Naming: lowercase kebab-case, a date suffix (`-YYYY-MM-DD`) on anything that is a snapshot of a day, `-ar` on an Arabic document.
